Zapret Mirrly GUI v1.1.8 — Оптимизация Telegram WS Proxy, система пулов и обновление экосистемы Mirrly

В версии v1.1.8 полностью переработан встроенный движок **Telegram WS Proxy**, внедрена многоуровневая система пулов и добавлена карточка мобильного приложения Mirrly TG Proxy (Android).

### Основные изменения и новшества v1.1.8:

1. **⚡ 64-битное SIMD-ускорение AES-CTR**:
   - Перевод шифрования на блочную 64-битную обработку `ulong`.
   - Плавное проигрывание 4K/1080p видео и быстрая загрузка медиафайлов без нагрузки на ядро процессора.

2. **🚀 Исправление Handshake и Ping Keep-Alive**:
   - Устранен баг с буферизацией `StreamReader` — 0% потерь первых кадров WebSocket.
   - Фоновая задача `pingTask` раз в 15 секунд отправляет WebSocket Ping для удержания сессии открытой при паузах.

3. **📊 Система пулов**:
   - **IP-Benchmark Pool**: непрерывный фоновый тест задержек (Ping/RTT) до 30+ IP-адресов Telegram и Cloudflare с авто-выбором быстрейшего узла.
   - **Smart Failover Pool**: мгновенный авто-переход на резервные каналы при блокировках.
   - **Domain Fronting Pool**: ротация SNI-доменов для защиты от DPI.

4. **📱 Панель Mirrly TG Proxy во вкладке «Поддержать»**:
   - Добавлена подробная карточка мобильного нативного прокси на Rust для Android.
