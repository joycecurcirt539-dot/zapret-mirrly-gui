Zapret Mirrly GUI v1.1.7 — Руководство по проксированию трафика на телефон (Tailscale + TgWsProxy)

В версии v1.1.7 добавлено подробное пошаговое руководство по превращению вашего домашнего компьютера в персональный узел разблокировок для мобильного телефона через 4G/5G, внедрена новая вкладка со всеми ссылками и кнопками, обновлен векторный интерфейс и оптимизировано копирование PowerShell команд.

Ключевые изменения и новшества:

1. 📱 Проксирование Telegram и всего трафика на телефон (Tailscale + TgWsProxy)
- Подробное руководство по настройке связки Tailscale (Exit Node), TgWsProxy и Windows PortProxy (`netsh`).
- Весь трафик телефона (YouTube 4K, Discord, сайты) проходит через ваш домашний ПК и Zapret.
- Telegram на мобильном телефоне подключается через WebSocket-маскированный туннель Cloudflare без блокировок ТСПУ.

2. 🚀 Интерактивная вкладка в разделе «Инструкция»
- Добавлена новая вкладка «Прокси на телефон (Tailscale + TgWsProxy)» в разделе Инструкция.
- Все элементы оформлены с помощью векторных математических иконок и без текстовых эмодзи.
- Прямой переход по кнопке «Инструкция» на карточке «Трансляция на телефон» в TgWsProxy прямо на подробный гайд.

3. ⚡ Скопировать скрипт PowerShell в один клик
- Добавлена кнопка «Скопировать скрипт», которая копирует в буфер обмена исключительно чистые исполняемые команды PowerShell без комментариев.

4. 📖 Документация в репозитории
- Подробная инструкция добавлена в конец файла `README.md` репозитория:
  https://github.com/joycecurcirt539-dot/zapret-mirrly-gui#readme

Установка:
Скачайте готовый автономный файл `ZapretMirrlyGUI.exe` из раздела Releases и запустите от имени Администратора.
